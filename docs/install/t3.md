# Install and update this T3 fork

T3 Code runs Compound Engineering through its Claude or Codex host. Install from **`GrantWasil/ce-t3`** to get the T3 dispatch adapter. The upstream `EveryInc/compound-engineering-plugin` install commands select a different repository.

The fork keeps the marketplace name `compound-engineering-plugin` and plugin ID `compound-engineering@compound-engineering-plugin`. The name and release version alone do not prove which repository supplied the installed files.

Run the commands below in a terminal using the same host profile as T3 Code. For a non-default profile, keep `CLAUDE_CONFIG_DIR` (Claude) or `CODEX_HOME` (Codex) consistent for installation, updates, and the T3 provider. Start a new T3 session after installing or updating.

## Claude

Check the configured source:

```bash
claude plugin marketplace list --json
```

If `compound-engineering-plugin` points to upstream, uninstall CE while retaining its saved data, then remove that marketplace before adding the fork:

```bash
claude plugin uninstall compound-engineering@compound-engineering-plugin --keep-data
claude plugin marketplace remove compound-engineering-plugin
```

Install:

```bash
claude plugin marketplace add GrantWasil/ce-t3
claude plugin install compound-engineering@compound-engineering-plugin
```

To update, refresh the marketplace and reinstall while retaining saved data:

```bash
claude plugin marketplace update compound-engineering-plugin
claude plugin uninstall compound-engineering@compound-engineering-plugin --keep-data
claude plugin install compound-engineering@compound-engineering-plugin
```

The fork can change skill files without changing its release-owned version. On Claude Code 2.1.312, `plugin update` reports `up_to_date` in that case and keeps the old files; the reinstall sequence refreshes them. If your Claude CLI does not support `--keep-data`, update Claude before using these commands.

## Codex

Check the configured source:

```bash
codex plugin marketplace list --json
```

If `compound-engineering-plugin` points to upstream, remove its installed plugin and marketplace before adding the fork:

```bash
codex plugin remove compound-engineering@compound-engineering-plugin
codex plugin marketplace remove compound-engineering-plugin
```

Install:

```bash
codex plugin marketplace add GrantWasil/ce-t3 --ref main
codex plugin add compound-engineering@compound-engineering-plugin
```

Update the fork snapshot and reinstall from it, including changes that keep the same release version:

```bash
codex plugin marketplace upgrade compound-engineering-plugin
codex plugin add compound-engineering@compound-engineering-plugin
```

## Verify the source and installed files

Run your host's `plugin marketplace list --json` and `plugin list --json` commands. The marketplace source must identify `GrantWasil/ce-t3`; the plugin must be installed and enabled. The installed plugin directory must contain `skills/ce-work/references/t3-dispatch.md`. Claude's plugin listing reports `installPath`; Codex's `plugin add --json` reports `installedPath`.

These checks establish the installed content. T3 dispatch also requires T3's orchestration tools in the host session. See [T3 configuration and behavior](../guides/configuration.md#under-t3-code).

## Develop directly from a checkout in Codex

For current branch files, including uncommitted edits, use the repository's local mode instead of a cached marketplace install:

```bash
git clone https://github.com/GrantWasil/ce-t3.git
cd ce-t3
bun install --frozen-lockfile
bun run codex:dev -- local
bun run codex:dev -- status
```

Use the [repository's pinned Bun version](../../README.md#repository-development) for development. Local mode links this checkout's skills and removes CE plugin installs from the selected Codex profile. It leaves unrelated skills alone. Start a new T3 Codex session after switching modes.

For a clean checkout tracking `main`, update with `git pull --ff-only`; the skill link sees those files directly. `bun run codex:dev -- status` reports the checkout and commit supplying the skills. **`codex:dev -- remote` restores upstream**, not this fork. To return to the fork marketplace, run `bun run codex:dev -- remove`, then use the Codex install steps above.
